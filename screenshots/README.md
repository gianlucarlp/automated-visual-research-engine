Independent desktop application for automated visual research and media mapping for audiovisual productions. The software analyzes SRT/script scenes and selectively queries Europeana for relevant historical, cultural and artistic material such as archival photographs, maps, paintings, manuscripts and artifacts. The Europeana Search API will be used to retrieve metadata, thumbnails, source links and rights information, prioritizing reusable/open-access items. Europeana will only be queried when cultural heritage content is relevant to the scene, and original attribution/rights information will be preserved.
